## Как протестировать 🧪

### Шаг 1: Перейти на страницу маршрутов
```
https://logistgo.pro/company/{company_id}/routes
```

### Шаг 2: Создать новый маршрут

1. **Нажмите "Добавить маршрут"**

2. **Выберите автомобиль (необязательно)**
   - Если у вас нет автомобилей, создайте их в разделе "Автопарк"

3. **Точка отправления**
   - Начните вводить "Минск"
   - Дождитесь появления подсказок от Nominatim
   - Выберите нужный город из списка
   - ✅ Проверьте, что выбранное значение отобразилось

4. **Промежуточные точки (НОВОЕ!)**
   - В поле "Промежуточные точки" введите "Любань"
   - Выберите город из списка
   - ✅ Проверьте, что точка добавилась в список ниже
   - Попробуйте добавить еще одну точку, например "Слуцк"
   - ✅ Проверьте, что обе точки отображаются
   - Попробуйте удалить одну точку (кнопка X)
   - ✅ Проверьте, что точка удалилась

5. **Точка прибытия**
   - Введите "Гомель"
   - Выберите из списка
   - ✅ Проверьте отображение

6. **Дата отправления (УЛУЧШЕНО!)**
   - Кликните на поле даты
   - ✅ Проверьте, что календарь открылся с темной темой
   - ✅ Проверьте, что текущая дата выделена серым
   - Выберите дату в будущем
   - ✅ Проверьте, что выбранная дата выделена синим
   - ✅ Проверьте, что дата отобразилась в поле

7. **Описание**
   - Введите любое описание, например:
     ```
     Доставка груза с остановками в промежуточных городах
     ```

8. **Создание маршрута**
   - Нажмите "Создать маршрут"
   - ✅ Проверьте, что появилось уведомление об успехе
   - ✅ Проверьте, что модальное окно закрылось
   - ✅ Проверьте, что маршрут появился в списке

### Шаг 3: Проверить отображение маршрута

✅ **Проверьте карточку маршрута:**
- Отображается маршрут: "Минск → Гомель"
- Если добавляли waypoints, они отображаются под маршрутом с иконкой навигации
- Отображается дата отправления
- Отображается описание
- Отображается информация об автомобиле (если выбран)
- Отображаются даты создания и обновления

### Шаг 4: Проверить формат данных в БД

Выполните SQL запрос:
```sql
SELECT 
  id_routes,
  departure_point,
  arrival_point,
  places_departure,
  places_arrival,
  date_start,
  opisanie
FROM routes 
ORDER BY created_at DESC 
LIMIT 1;
```

✅ **Проверьте формат places_departure:**
```json
{
  "625144": {
    "lat": 53.9006011,
    "lon": 27.558972,
    "waypoints": [
      {
        "place_id": 3076353,
        "lat": 52.7919112,
        "lon": 27.9994587,
        "name": "Любань, Любанский район, Минская область, Беларусь"
      }
    ]
  }
}
```

### Шаг 5: Удаление маршрута

1. Нажмите на кнопку удаления (красная иконка корзины)
2. ✅ Проверьте, что открылось модальное окно подтверждения
3. ✅ Проверьте, что в окне отображается информация о маршруте
4. Нажмите "Удалить"
5. ✅ Проверьте, что маршрут удалился из списка
6. ✅ Проверьте, что появилось уведомление об успехе

## Возможные проблемы и решения ❓

### Nominatim не находит места
**Решение:** 
- Убедитесь, что API_BASE правильно настроен
- Проверьте работу прокси `/api/nominatim/places/search`

### Waypoints не сохраняются
**Решение:**
- Проверьте консоль браузера на ошибки
- Убедитесь, что backend schema обновлена
- Проверьте валидацию в routes.schema.ts

### Календарь не отображается
**Решение:**
- Проверьте, что файл `calendar.css` импортирован
- Убедитесь, что `react-day-picker` установлен:
  ```bash
  cd apps/frontend
  npm install react-day-picker@^9.11.1
  ```

### Стили календаря некорректны
**Решение:**
- Проверьте путь импорта: `@/styles/calendar.css`
- Убедитесь, что файл создан в `apps/frontend/src/styles/calendar.css`

```

```

```
Content-Type: application/json

{
  "id_cars": 42,

  "places_arrival": {...},

  "opisanie": "Описание маршрута"
}
```

```
DELETE /api/routes/{id_routes}
```
