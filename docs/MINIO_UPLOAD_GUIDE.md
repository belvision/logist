## 📐 Рекомендуемые размеры изображений

### Для Hero-секций (главные фоны)

**Оптимальные размеры:**
- **Ширина**: 1920px - 2560px
- **Высота**: 1080px - 1440px
- **Соотношение сторон**: 16:9 или 21:9 (широкоформатное)

**Почему такие размеры:**
- 1920x1080px (Full HD) - стандарт для большинства мониторов
- 2560x1440px (2K) - для больших экранов и Retina-дисплеев
- Современные браузеры автоматически оптимизируют изображения

**Минимальные размеры:**
- Не менее 1920x1080px для качественного отображения

**Максимальные размеры:**
- Не более 3840x2160px (4K) - больше не нужно, только увеличит размер файла

### Для других секций (если понадобятся)

- **Секции с карточками**: 1920x600px - 1920x800px
- **CTA-блоки**: 1920x400px - 1920x600px
- **Футеры**: 1920x300px - 1920x500px

## 💾 Оптимизация файлов

### Рекомендуемый размер файла

- **Для JPG**: 200KB - 500KB (оптимально ~300KB)
- **Для WebP**: 100KB - 300KB (оптимально ~200KB)

### Форматы файлов

1. **JPG** (рекомендуется)
   - Лучшее качество при меньшем размере
   - Поддержка всеми браузерами
   - Идеально для фотографий

2. **WebP** (альтернатива)
   - Еще меньше размер при том же качестве
   - Поддержка современными браузерами
   - Автоматический fallback на JPG

3. **PNG** (не рекомендуется для фонов)
   - Слишком большой размер файла
   - Используйте только если нужна прозрачность

### Инструменты для оптимизации

**Онлайн-сервисы:**
- [TinyPNG](https://tinypng.com/) - сжатие JPG/PNG
- [Squoosh](https://squoosh.app/) - продвинутая оптимизация от Google
- [ImageOptim](https://imageoptim.com/) - для Mac

**Программы:**
- **Photoshop**: File → Export → Save for Web
- **GIMP**: File → Export As → настройка качества
- **XnConvert**: бесплатная программа для пакетной обработки

## 🎨 Рекомендации по изображениям

### Что должно быть на изображении

1. **Фокус в центре** - важные элементы должны быть по центру
2. **Темные области** - для лучшей читаемости белого текста
3. **Нейтральные цвета** - не слишком яркие, чтобы не отвлекать от контента
4. **Высокий контраст** - для лучшей видимости текста поверх изображения

### Что НЕ должно быть на изображении

1. ❌ Много мелких деталей - отвлекают от текста
2. ❌ Слишком яркие цвета - мешают читать текст
3. ❌ Текст на изображении - будет конфликтовать с контентом страницы
4. ❌ Лица людей крупным планом - могут отвлекать

### Примеры хороших фонов

- Грузовики/машины в движении (размыто, в фоне)
- Складские помещения (общий план)
- Дороги/магистрали (вид сверху или сбоку)
- Абстрактные геометрические формы
- Градиенты с текстурами

## 🔄 Как заменить изображение

### Вариант 1: Замена через MinIO Console

1. Откройте MinIO Console
2. Перейдите в нужную папку (например, `backgrounds/home/`)
3. Найдите файл `hero-bg.jpg`
4. Удалите старый файл (опционально, но рекомендуется)
5. Загрузите новый файл с тем же именем `hero-bg.jpg`
6. Изображение автоматически обновится на сайте (может потребоваться очистка кэша браузера)

### Вариант 2: Загрузка с новым именем

1. Загрузите новое изображение с другим именем (например, `hero-bg-v2.jpg`)
2. Обновите конфигурацию в `apps/frontend/src/lib/background-images.ts`:
   ```typescript
   home: {
     hero: getBackgroundImageUrl('home/hero-bg-v2.jpg'), // измените имя
   },
   ```
3. Перезапустите frontend или просто обновите страницу

## 🐛 Решение проблем

### Изображение не отображается

1. Проверьте URL в браузере напрямую
2. Убедитесь, что файл загружен в правильную папку
3. Проверьте имя файла (должно точно совпадать с конфигурацией)
4. Очистите кэш браузера (Ctrl+Shift+R или Cmd+Shift+R)

### Изображение слишком большое/маленькое

- Используйте CSS для настройки: `background-size: cover` (уже применено в компоненте)
- Убедитесь, что изображение имеет правильное соотношение сторон

### Изображение загружается медленно

- Оптимизируйте размер файла (должен быть < 500KB)
- Используйте формат WebP для еще лучшей оптимизации
- Проверьте скорость интернета
