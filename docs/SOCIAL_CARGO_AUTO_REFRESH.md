# Управление автообновлением страницы социальных грузов

## 🎮 Функциональность

Страница `/social-cargo` теперь имеет интерактивный индикатор обновления с возможностью управления.

## ✨ Возможности

### 1. Индикатор последнего обновления
- **Расположение:** Вверху страницы в hero-секции
- **Отображает:** Точное время последнего обновления в формате `HH:mm:ss`
- **Визуальная индикация:** Иконка с пульсацией когда автообновление активно

### 2. Кнопка ручного обновления
- **Иконка:** ↻ (RefreshCw)
- **Действие:** Принудительно обновляет данные
- **Визуальная обратная связь:** Анимация вращения во время загрузки
- **Состояние:** Отключается во время загрузки

### 3. Кнопка управления автообновлением
- **Иконка:** ⏸ (Pause) / ▶ (Play)
- **Действие:** Включает/выключает автоматическое обновление каждые 5 секунд
- **По умолчанию:** Автообновление включено

## 🎨 Внешний вид

```
┌─────────────────────────────────────────────────────────┐
│  🔄 Обновлено: 16:47:32  │  ↻  ⏸                        │
└─────────────────────────────────────────────────────────┘
```

**Элементы:**
- 🔄 - Иконка обновления (пульсирует при включенном автообновлении)
- Время - Последнее обновление
- ↻ - Кнопка ручного обновления
- ⏸/▶ - Кнопка паузы/запуска автообновления

## 💻 Технические детали

### State управления
```tsx
const [lastUpdate, setLastUpdate] = useState<Date | null>(null);
const [isAutoRefreshEnabled, setIsAutoRefreshEnabled] = useState(true);
```

### Автообновление
```tsx
// Автообновление каждые 5 секунд (если включено)
useEffect(() => {
  if (!isAutoRefreshEnabled) return;
  
  const interval = setInterval(() => {
    fetchCargos();
  }, 5000);

  return () => clearInterval(interval);
}, [fetchCargos, isAutoRefreshEnabled]);
```

### Ручное обновление
```tsx
const handleManualRefresh = () => {
  fetchCargos();
};
```

### Переключение автообновления
```tsx
const toggleAutoRefresh = () => {
  setIsAutoRefreshEnabled(prev => !prev);
};
```

## 🔧 Стили кнопок

```tsx
// Кнопка ручного обновления
<button
  onClick={handleManualRefresh}
  disabled={loading}
  className="p-2 hover:bg-white/20 rounded-full transition-all disabled:opacity-50"
  title="Обновить сейчас"
>
  <RefreshCw className={`h-4 w-4 ${loading ? 'animate-spin' : ''}`} />
</button>

// Кнопка паузы/запуска
<button
  onClick={toggleAutoRefresh}
  className="p-2 hover:bg-white/20 rounded-full transition-all"
  title={isAutoRefreshEnabled ? 'Остановить автообновление' : 'Запустить автообновление'}
>
  {isAutoRefreshEnabled ? <Pause /> : <Play />}
</button>
```

## 🎯 Сценарии использования

### Сценарий 1: Пользователь хочет сэкономить трафик
1. Нажимает на кнопку ⏸ (Pause)
2. Автообновление останавливается
3. Иконка меняется на ▶ (Play)
4. Пульсация индикатора прекращается

### Сценарий 2: Пользователь хочет увидеть свежие данные сразу
1. Нажимает на кнопку ↻ (Refresh)
2. Данные обновляются немедленно
3. Время обновления меняется на текущее
4. Кнопка показывает анимацию загрузки

### Сценарий 3: Пользователь возобновляет автообновление
1. Нажимает на кнопку ▶ (Play)
2. Автообновление возобновляется
3. Иконка меняется на ⏸ (Pause)
4. Пульсация индикатора возобновляется

## 📱 Адаптивность

Индикатор полностью адаптивен:
- **Desktop:** Полное отображение всех элементов
- **Tablet:** Компактное отображение
- **Mobile:** Оптимизированный размер кнопок для касаний

## ✅ Преимущества

1. **Экономия трафика** - можно отключить автообновление
2. **Контроль** - ручное обновление по требованию
3. **Прозрачность** - видно когда данные обновлялись последний раз
4. **UX** - интуитивно понятные иконки и подсказки
5. **Производительность** - отключение автообновления снижает нагрузку

## 🐛 Обработка ошибок

- Кнопка ручного обновления отключается во время загрузки
- Анимация показывает процесс обновления
- Ошибки отображаются в карточке под индикатором
