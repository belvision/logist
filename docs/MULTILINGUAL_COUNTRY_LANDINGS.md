## 🏗️ Архитектура

### Файловая структура

```
apps/frontend/src/
├── data/
│   └── countries.ts              # Данные всех стран с переводами
├── components/
│   └── CountryCard.tsx           # Компонент карточки страны
├── app/
│   ├── page.tsx                  # Главная страница с секцией стран
│   └── countries/
│       └── [slug]/
│           └── page.tsx          # Динамическая страница страны
```

### Компоненты

#### 1. `countries.ts` - Данные стран

Содержит структурированные данные для каждой страны:

```typescript
export interface CountryData {
  code: string;           // ISO код (BY, RU, KZ, и т.д.)
  slug: string;           // URL slug
  nameRu: string;         // Название на русском
  nameLocal?: string;     // Название на местном языке
  flag: string;           // Эмодзи флага
  languages: string[];    // Список языков
  description: {
    ru: string;
    local?: string;
  };
  keywords: string[];     // SEO ключевые слова
  content: {              // Контент страницы
    hero: { ... },
    features: { ... }
  };
}
```

#### 2. `CountryCard.tsx` - Карточка страны

Отображает информацию о стране на главной странице:
- Флаг страны (emoji)
- Название на русском и местном языке
- Краткое описание
- Кнопка "Подробнее" с ссылкой на лендинг

#### 3. `[slug]/page.tsx` - Динамическая страница страны

Использует Next.js Dynamic Routes для генерации статических страниц для каждой страны.

**Особенности:**
- ✅ Server-Side Rendering (SSR)
- ✅ Static Generation (SSG) с `generateStaticParams`
- ✅ Динамические метаданные с `generateMetadata`
- ✅ Многоязычный контент
- ✅ Структурированные данные Schema.org

## 🔍 SEO Оптимизация

### Метаданные

Каждая страница имеет уникальные метаданные:

```typescript
{
  title: `${country.nameRu} | Биржа грузоперевозок LogistGo.pro`,
  description: country.description.ru,
  keywords: country.keywords,
  alternates: {
    canonical: `/countries/${country.slug}`,
  },
  openGraph: {
    title: `LogistGo.pro в ${country.nameRu} ${country.flag}`,
    description: country.description.ru,
    url: `https://logistgo.pro/countries/${country.slug}`,
    type: 'website',
  },
}
```

## 🚀 Развертывание

### Статическая генерация

Все страницы стран генерируются статически при сборке:

```typescript
export async function generateStaticParams() {
  return getCountrySlugs().map((slug) => ({
    slug: slug,
  }));
}
```

### Проверка после развертывания

1. **Проверить доступность всех страниц:**
```bash
https://logistgo.pro/countries/belarus
https://logistgo.pro/countries/russia
https://logistgo.pro/countries/kazakhstan
# ... и т.д. для всех стран
```

2. **Проверить мета-теги:**
   - Открыть View Page Source
   - Найти `<meta name="description">`
   - Проверить наличие Open Graph тегов

3. **Проверить sitemap.xml:**
```bash
https://logistgo.pro/sitemap.xml
```

4. **Проверить robots.txt:**
```bash
https://logistgo.pro/robots.txt
```

## 🔧 Добавление новой страны

### Шаг 1: Добавить данные в `countries.ts`

```typescript
{
  code: 'XX',
  slug: 'country-name',
  nameRu: 'Название',
  nameLocal: 'Local Name',
  flag: '🇽🇽',
  languages: ['ru', 'xx'],
  description: {
    ru: 'Описание на русском...',
    local: 'Description in local language...',
  },
  keywords: ['keyword1', 'keyword2'],
  content: {
    hero: { ... },
    features: { ... }
  },
}
```

### Шаг 2: Обновить sitemap.xml

```xml
<url>
  <loc>https://logistgo.pro/countries/country-name</loc>
  <lastmod>2025-10-24</lastmod>
  <changefreq>weekly</changefreq>
  <priority>0.9</priority>
</url>
```

### Шаг 3: Обновить robots.txt

```
Allow: /countries/country-name
```

### Шаг 4: Пересобрать и развернуть

```bash
npm run build
npm run deploy
```
