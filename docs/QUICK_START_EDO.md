## 🎯 Как запустить

### 1. Установка зависимостей
```bash
cd apps/backend
npm install
```

### 2. Миграция БД
```bash
npm run db:push
```

### 3. Загрузка шаблонов
```bash
npx tsx src/db/seed-documents.ts
```

### 4. Запуск backend
```bash
npm run dev
```

### 5. Запуск frontend (в другом терминале)
```bash
cd apps/frontend
npm run dev
```

## 📍 Как попасть в ЭДО

1. Войдите в систему
2. Выберите компанию
3. В левом меню нажмите **"Документы"** 📄
4. Или перейдите по адресу: `/company/{company_id}/documents`

## 🔧 Если что-то не работает

1. **Puppeteer ошибки**: 
   ```bash
   npm install puppeteer --force
   ```

2. **Права доступа к файлам**:
   ```bash
   mkdir -p uploads/documents
   chmod 755 uploads/documents
   ```

3. **TypeScript ошибки**:
   ```bash
   cd apps/backend
   npm run type-check
   ```
