# Страница деталей автомобиля и интеграция с мессенджером

## Что было реализовано

### 1. Страница деталей автомобиля
**Путь:** `/company/[company_id]/car-search/[id]/page.tsx`

Создана полноценная страница для просмотра деталей автомобиля с следующими возможностями:

#### Основная информация:
- Название и ID автомобиля
- Тип автомобиля
- Грузоподъемность (мин/макс в тоннах)
- Объем (мин/макс в м³)
- Тип загрузки
- Цена (если указана)
- Список местоположений автомобиля с координатами

#### Информация о компании:
- Название компании и форма собственности
- УНП
- Юридический адрес
- Контактные телефоны
- Email

#### Действия:
- **Написать водителю** - создает/открывает беседу в мессенджере
- **Позвонить** - открывает телефонное приложение
- **Написать email** - открывает почтовый клиент

### 2. Интеграция с мессенджером

#### Обновлен компонент Messenger
**Файл:** `apps/frontend/src/components/messenger/Messenger.tsx`

Добавлена возможность автоматически открывать конкретную беседу:
- Новый проп `initialConversationId?: string`
- Автоматическая загрузка беседы при монтировании компонента
- Метод `loadConversation()` для загрузки беседы по ID

#### Обновлена страница мессенджера
**Файл:** `apps/frontend/src/app/company/[company_id]/messenger/page.tsx`

Добавлена поддержка URL параметра `conversation`:
- Чтение параметра из URL: `?conversation=<conversation_id>`
- Передача ID беседы в компонент Messenger
- Автоматическое открытие беседы при переходе по ссылке

#### Обновлена страница поиска автомобилей
**Файл:** `apps/frontend/src/app/company/[company_id]/car-search/page.tsx`

- Кнопка "Подробнее" теперь ведет на страницу деталей автомобиля
- Добавлен `useParams` для получения `company_id`

### 3. Функционал "Написать водителю"

При нажатии на кнопку "Написать водителю":
1. Определяется владелец автомобиля (через `car.owner.id_user` или `car.id_company`)
2. Проверяется, что пользователь не пытается написать самому себе
3. Создается новая беседа или открывается существующая через `messengerApi.createConversation()`
4. Происходит редирект в мессенджер с параметром `conversation` в URL
5. Мессенджер автоматически открывает эту беседу

## Использование

### Переход на страницу деталей автомобиля:
```
/company/{company_id}/car-search/{car_id}
```

### Открытие конкретной беседы в мессенджере:
```
/company/{company_id}/messenger?conversation={conversation_id}
```

## API endpoints используемые

### Frontend API:
- `GET /api/cars/:id` - получение деталей автомобиля
- `POST /messenger/conversations` - создание новой беседы
- `GET /messenger/conversations/:id` - получение беседы по ID

### Backend endpoints:
Используется существующий endpoint для получения автомобиля:
- `GET /api/cars/:id` (с аутентификацией)
