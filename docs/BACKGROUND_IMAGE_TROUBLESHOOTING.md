# Устранение проблем с фоновыми изображениями

## ✅ Файл переименован!

Файл `hero-bg.web` переименован в `hero-bg.webp` ✅

## 🔍 Проверка

### 1. Проверьте доступность изображения

Откройте в браузере:
```
https://io.logistgo.pro/logistic-pro/backgrounds/carriers/hero-bg.webp
```

Если изображение открывается - все правильно!

### 2. Обновите страницу с очисткой кэша

На странице `http://localhost:3000/carriers`:
- Нажмите **Ctrl+Shift+R** (жесткая перезагрузка)
- Или **Ctrl+F5**

### 3. Проверьте консоль браузера

1. Откройте DevTools (F12)
2. Перейдите на вкладку **Console**
3. Проверьте, нет ли ошибок загрузки изображения

### 4. Проверьте Network вкладку

1. В DevTools → **Network**
2. Обновите страницу (F5)
3. Найдите запрос к `hero-bg.webp`
4. Проверьте статус:
   - **200 OK** ✅ - файл загружается
   - **404** ❌ - файл не найден
   - **403** ❌ - нет доступа

## 🐛 Если изображение все еще не видно

### Проблема 1: Кэш браузера

**Решение:**
- Очистите кэш браузера (Ctrl+Shift+Delete)
- Или используйте режим инкогнито

### Проблема 2: CORS ошибка

**Решение:**
Проверьте, что MinIO разрешает запросы с localhost. В продакшене это должно работать.

### Проблема 3: Изображение загружается, но не видно

**Решение:**
Проверьте в DevTools → Elements → найдите элемент с `BackgroundImage` и проверьте стили.

- ✅ Паттерн поверх изображения (опционально)
