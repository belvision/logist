# Рекомендуемые размеры изображений для страницы "7 шагов"

## 📐 Структура страницы

Страница использует контейнер с максимальной шириной `max-w-6xl` (1152px).

Каждый шаг отображается в карточке с flex-структурой:
- **Левая часть** (на десктопе): `md:w-1/3` ≈ **384px**
- **Правая часть** (на десктопе): `md:w-2/3` ≈ **768px**

## 🖼️ Варианты размещения изображений

### Вариант 1: Изображение в левой части (вместо/вместе с иконкой)

**Рекомендуемые размеры:**
- **Ширина:** 400-500px (для Retina дисплеев)
- **Высота:** 300-400px (соотношение 4:3 или 5:4)
- **Формат:** WebP или JPG
- **Размер файла:** 50-150 KB

**Пример:**
```
step-1-image.webp: 500x375px (4:3)
step-2-image.webp: 500x375px (4:3)
...
```

### Вариант 2: Изображение в правой части (над/под текстом)

**Рекомендуемые размеры:**
- **Ширина:** 800-1000px (для Retina дисплеев)
- **Высота:** 450-600px (соотношение 16:9 или 5:3)
- **Формат:** WebP или JPG
- **Размер файла:** 100-250 KB

**Пример:**
```
step-1-content.webp: 1000x563px (16:9)
step-2-content.webp: 1000x563px (16:9)
...
```

### Вариант 3: Фоновое изображение для всего шага

**Рекомендуемые размеры:**
- **Ширина:** 1200-1400px (для Retina дисплеев)
- **Высота:** 400-500px (соотношение 3:1 или 2.5:1)
- **Формат:** WebP или JPG
- **Размер файла:** 150-300 KB

**Пример:**
```
step-1-bg.webp: 1400x560px (2.5:1)
step-2-bg.webp: 1400x560px (2.5:1)
...
```

## 📱 Адаптивность

На мобильных устройствах (`< 768px`):
- Flex-структура меняется на вертикальную
- Изображения должны масштабироваться автоматически
- Рекомендуется использовать `srcset` для разных разрешений

## ✅ Рекомендации

### Для левой части (иконка/иллюстрация):
```
Размер: 500x375px (4:3)
Формат: WebP
Размер файла: 50-100 KB
```

### Для правой части (контентное изображение):
```
Размер: 1000x563px (16:9)
Формат: WebP
Размер файла: 100-200 KB
```

### Для фонового изображения:
```
Размер: 1400x560px (2.5:1)
Формат: WebP
Размер файла: 150-250 KB
```

## 🎨 Оптимизация

1. **Используйте WebP формат** для лучшего сжатия
2. **Оптимизируйте изображения** перед загрузкой (TinyPNG, Squoosh)
3. **Используйте lazy loading** для изображений ниже первого экрана
4. **Добавьте alt-тексты** для SEO и доступности
