# Грузы из соц сетей в личном кабинете

## 📋 Описание

Добавлена новая вкладка "Грузы из соц сетей" в раздел "Грузы" личного кабинета с отображением телефонов для авторизованных пользователей.

## 🎯 Функциональность

### Отличия от публичной версии

| Функция | Публичная страница | Личный кабинет |
|---------|-------------------|----------------|
| Доступ | Без авторизации | Требуется авторизация |
| Телефоны | Скрыты (кнопка "Показать контакты") | ✅ Отображаются |
| Дизайн | Светлый + темная тема | Темный дизайн ЛК |
| Layout | LandingLayout | AppLayout |

## 📍 Расположение

**Путь:** `/company/[company_id]/social-cargo`

**Навигация:**
```
Личный кабинет
  └─ Грузы 📦
      ├─ Мои грузы 📋
      ├─ Поиск попутных грузов 🔍
      └─ Грузы из соц сетей 🌐 ← НОВОЕ
```

## 🎨 Дизайн

### Цветовая схема (темная тема ЛК)

**Карточки грузов:**
- Фон: `bg-gray-800/50`
- Граница: `border-gray-700`
- Hover: `bg-gray-800/70 border-gray-600`

**Заголовок карточки:**
- Градиент: `from-blue-900/20 to-indigo-900/20`
- Граница: `border-gray-700`

**Информационные блоки:**
- Вес: синий (`bg-blue-900/20 border-blue-800`)
- Цена: зеленый (`bg-green-900/20 border-green-800`)
- Даты: индиго (`bg-indigo-900/20 border-indigo-800`)
- Тип авто: фиолетовый (`bg-purple-900/20 border-purple-800`)

**Телефоны:**
- Фон: `bg-green-900/20`
- Hover: `bg-green-900/30`
- Граница: `border-green-800`
- Иконка: зеленая

## 📱 Отображение телефонов

### Пример кода:

```tsx
<div className="mt-4 space-y-2">
  {cargo.tel_1 && (
    <a 
      href={`tel:${cargo.tel_1}`}
      className="flex items-center gap-2 text-sm bg-green-900/20 hover:bg-green-900/30 p-3 rounded-lg border border-green-800 hover:border-green-700 transition-all"
    >
      <Phone className="h-4 w-4 text-green-400" />
      <span className="text-white font-medium">{cargo.tel_1}</span>
    </a>
  )}
  {cargo.tel_2 && (
    <a 
      href={`tel:${cargo.tel_2}`}
      className="flex items-center gap-2 text-sm bg-green-900/20 hover:bg-green-900/30 p-3 rounded-lg border border-green-800 hover:border-green-700 transition-all"
    >
      <Phone className="h-4 w-4 text-green-400" />
      <span className="text-white font-medium">{cargo.tel_2}</span>
    </a>
  )}
</div>
```

### Функциональность телефонов:
- ✅ Кликабельные ссылки `tel:`
- ✅ Hover эффект
- ✅ Иконка телефона
- ✅ До 2 телефонов на груз
- ✅ Автоматически скрываются если пусто

## 🚀 Использование

1. Войдите в личный кабинет
2. Откройте раздел "Грузы 📦"
3. Выберите "Грузы из соц сетей 🌐"
4. Просматривайте грузы с телефонами
5. Кликайте на телефон для звонка
