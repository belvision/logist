# Исправления проблем безопасности и входа

## 🚨 Проблемы, которые были исправлены:

### 1. **WebSocket "Insufficient resources"**
- ✅ Устранены дублирующие WebSocket серверы
- ✅ Добавлено управление соединениями (лимит 3 на пользователя)
- ✅ Реализован ping/pong heartbeat
- ✅ Улучшена логика переподключения с экспоненциальным backoff

### 2. **Ошибка "Проверка безопасности не пройдена"**
- ✅ Увеличено количество попыток входа: 10 → 20 за 15 минут
- ✅ Снижен минимальный score reCAPTCHA: 0.5 → 0.3
- ✅ Добавлена поддержка отключения reCAPTCHA в продакшене

### 3. **Конфигурация nginx**
- ✅ Исправлен порт backend: 8080 → 5555
- ✅ Добавлена конфигурация WebSocket для `/notifications`
- ✅ Улучшены timeout'ы для WebSocket соединений

## 🔧 Что нужно сделать:

### **Срочно (для исправления ошибки входа):**

1. **Создайте файл `.env` в `apps/backend/`:**
```bash
NODE_ENV=production
PORT=5555
RECAPTCHA_SITE_KEY=REDACTED_SECRET
RECAPTCHA_SECRET_KEY=ВАШ_СЕКРЕТНЫЙ_КЛЮЧ_ЗДЕСЬ
RECAPTCHA_MIN_SCORE=0.3
```

2. **Получите SECRET KEY:**
   - Перейдите в [Google reCAPTCHA Admin Console](https://www.google.com/recaptcha/admin)
   - Найдите сайт `logistgo.pro`
   - Скопируйте **SECRET KEY** (не SITE KEY!)

3. **Обновите nginx конфигурацию:**
   - Используйте файл `nginx-fixed.conf`
   - Перезагрузите nginx: `sudo systemctl reload nginx`

### **Альтернативно (временно):**

Если нужно быстро исправить, добавьте в `apps/frontend/.env.local`:
```bash
NEXT_PUBLIC_DISABLE_RECAPTCHA=true
```
