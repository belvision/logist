# Функционал: Грузы из социальных сетей

## Описание
Публичная страница для просмотра актуальных грузов из социальных сетей без необходимости авторизации. Грузы собираются из различных источников (Telegram, Instagram, ВКонтакте) и хранятся в таблице `public.cargo_messendger`.

## Реализованные функции

### ✅ 1. Backend API
**Путь:** `/api/social-cargo`

**Файлы:**
- `apps/backend/src/api/social-cargo/social-cargo.types.ts` - типы данных
- `apps/backend/src/api/social-cargo/social-cargo.schema.ts` - валидация запросов
- `apps/backend/src/api/social-cargo/social-cargo.repository.ts` - работа с БД
- `apps/backend/src/api/social-cargo/social-cargo.service.ts` - бизнес-логика
- `apps/backend/src/api/social-cargo/social-cargo.router.ts` - роутинг (Hono)

**Endpoint:**
```
GET /api/social-cargo?limit=20&offset=0&contains=Москва&notContains=срочно
```

**Query параметры:**
- `limit` (number, default: 20, max: 250) - количество грузов
- `offset` (number, default: 0) - смещение для пагинации
- `contains` (string, optional) - фильтр: объявление содержит
- `notContains` (string, optional) - фильтр: объявление не содержит

**Ответ:**
```json
{
  "success": true,
  "data": [...],
  "pagination": {
    "total": 150,
    "limit": 20,
    "offset": 0,
    "hasMore": true
  }
}
```

**Особенности:**
- ✅ Публичный доступ (без авторизации)
- ✅ Фильтрация по ключевым словам (содержит/не содержит)
- ✅ Поиск работает по всем текстовым полям (departure_point, arrival_point, opisanie, price)
- ✅ Максимальный лимит: 250 грузов
- ✅ Только актуальные грузы (irrelevant = 0)
- ✅ Телефоны НЕ возвращаются для незарегистрированных пользователей

### ✅ 2. Frontend Page
**Путь:** `/social-cargo`

**Файлы:**

- `apps/frontend/src/types/social-cargo.ts` - типы
- `apps/frontend/src/shared/api/social-cargo.ts` - API функции

**Функционал:**

#### 📊 Отображение грузов
- Отображается 20 самых свежих грузов по умолчанию
- Красивые карточки с полной информацией:
  - Маршрут (откуда → куда)
  - Вес (тонны)
  - Цена
  - Даты погрузки/разгрузки
  - Тип транспорта
  - Описание

#### 🔄 Автообновление
- **Автоматическое обновление каждые 5 секунд**
- Новые грузы появляются автоматически
- Индикатор загрузки при обновлении

#### 📄 Пагинация
- Начальный лимит: **20 грузов**
- Кнопка "Показать еще" увеличивает лимит на 20
- Максимальный лимит: **250 грузов**
- Счетчик: показано X из Y грузов

#### 🔍 Фильтры
**Два поля фильтрации:**

1. **"Объявление содержит"**
   - Поиск по ключевым словам
   - Ищет в: городах отправления/прибытия, описании, цене
   - ✨ **Поддержка запятых**: можно вводить несколько слов через запятую
   - Пример: `Москва, срочно, попутный`
   - Логика: **ВСЕ** слова должны быть найдены (AND)

2. **"Объявление НЕ содержит"**
   - Исключает объявления с указанными словами
   - ✨ **Поддержка запятых**: можно вводить несколько слов через запятую
   - Пример: `срочно, попутный, груз 200`
   - Логика: **НИ ОДНО** из слов не должно быть найдено

**Применение фильтров:**
- Кнопка "Применить фильтры"
- Визуальные теги активных фильтров (каждое слово отдельным тегом)
- Зеленые теги с ✓ для "содержит"
- Красные теги с ✗ для "не содержит"
- Сброс лимита при применении фильтров

#### 🔒 Скрытие телефонов
- Телефоны **НЕ отображаются** для незарегистрированных пользователей
- Кнопка "Показать контакты" вместо телефонов

## API Примеры

### Получить 20 последних грузов
```bash
curl http://localhost:3001/api/social-cargo
```

### Поиск грузов с фильтром
```bash
curl "http://localhost:3001/api/social-cargo?contains=Москва&limit=40"
```

### Поиск с несколькими словами (через запятую)
```bash
curl "http://localhost:3001/api/social-cargo?contains=Москва,срочно,попутный"
```
*Найдет грузы, которые содержат ВСЕ три слова*

### Исключить грузы
```bash
curl "http://localhost:3001/api/social-cargo?notContains=срочно"
```

### Исключить несколько слов
```bash
curl "http://localhost:3001/api/social-cargo?notContains=срочно,попутный,груз%20200"
```
*Исключит грузы, содержащие ЛЮБОЕ из этих слов*

### Комбинированные фильтры
```bash
curl "http://localhost:3001/api/social-cargo?contains=Минск,фура&notContains=попутный,срочно&limit=50"
```
*Найдет грузы с "Минск" И "фура", исключив "попутный" И "срочно"*
