# Отображение телефонов на странице социальных грузов

## 🎯 Изменения

### 1. Проверка авторизации
- Добавлена проверка авторизации пользователя через `useAuth()`
- Разное отображение для авторизованных и неавторизованных

### 2. Убрано поле "Цена"
- ❌ Удален блок с ценой
- Изменена сетка с 4 колонок на 3:
  - Вес (т)
  - Даты
  - Тип автомобиля

### 3. Отображение телефонов для авторизованных

#### Для авторизованных пользователей:
```tsx
{user ? (
  <div className="grid grid-cols-1 md:grid-cols-2 gap-2">
    {/* Основной телефон */}
    <a href={`tel:${cargo.tel_1}`}>
      <Phone icon />
      Основной: {cargo.tel_1}
    </a>
    
    {/* Дополнительный (если есть) */}
    {cargo.tel_2 && (
      <a href={`tel:${cargo.tel_2}`}>
        <Phone icon />
        Дополнительный: {cargo.tel_2}
      </a>
    )}
  </div>
) : (
  <Button onClick={openModal}>
    Показать контакты
  </Button>
)}
```

#### Особенности:
- ✅ Две колонки на десктопе
- ✅ Одна колонка на мобильных
- ✅ Кликабельные ссылки `tel:`
- ✅ Подписи "Основной" / "Дополнительный"
- ✅ Скрывается если `tel_2` пустой

### 4. Улучшенное модальное окно

#### До:
- Не было центрирования
- Слабая контрастность в темной теме
- Простой дизайн

#### После:
```tsx
<div className="fixed inset-0 z-[999999] flex items-center justify-center bg-black/70 backdrop-blur-sm p-4">
  <Card className="w-full max-w-md bg-white dark:bg-gray-800 border-2 border-gray-200 dark:border-gray-700 shadow-2xl">
    <CardHeader className="border-b border-gray-200 dark:border-gray-700 bg-gradient-to-r from-blue-50 to-indigo-50 dark:from-gray-700/50 dark:to-gray-600/50">
      <CardTitle className="text-center text-2xl font-bold text-gray-900 dark:text-white">
        Требуется регистрация
      </CardTitle>
    </CardHeader>
    <CardContent className="space-y-6 pt-6">
      {/* Иконка */}
      <div className="w-16 h-16 bg-gradient-to-br from-blue-600 to-indigo-600 rounded-full">
        <LogIn icon />
      </div>
      {/* Текст */}
      <p className="text-gray-700 dark:text-gray-300">...</p>
      {/* Кнопки */}
      <Link href="/registry">Зарегистрироваться</Link>
      <Link href="/login">Войти</Link>
      <Button onClick={close}>Закрыть</Button>
    </CardContent>
  </Card>
</div>
```

#### Улучшения модального окна:
- ✅ **Центрировано** - `flex items-center justify-center`
- ✅ **Темная тема** - `dark:bg-gray-800`, `dark:text-white`
- ✅ **Затемнение фона** - `bg-black/70 backdrop-blur-sm`
- ✅ **Градиентный заголовок**
- ✅ **Иконка** - круг с LogIn иконкой
- ✅ **Адаптивные кнопки** - 2 колонки на десктопе, 1 на мобильных

## 📱 Адаптивность

### Desktop (md и больше):
- Телефоны в 2 колонки
- Информация в 3 колонки
- Модальное окно - кнопки в ряд

### Mobile:
- Телефоны в 1 колонку
- Информация в 1 колонку
- Модальное окно - кнопки столбцом
