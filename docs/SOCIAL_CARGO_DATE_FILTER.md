# Фильтр по дате окончания грузов из социальных сетей

## Дата: 28 октября 2025

## Задача

Добавить автоматический фильтр на страницы социальных грузов, чтобы отображались только актуальные грузы - те, у которых дата окончания не раньше сегодняшнего дня.

## Затронутые страницы

1. **Публичная страница:** [https://logistgo.pro/social-cargo](https://logistgo.pro/social-cargo)
2. **Страница компании:** `/company/[company_id]/social-cargo`

## Реализация

### Backend изменения

**Файл:** `apps/backend/src/api/social-cargo/social-cargo.repository.ts`

**Что добавлено:**

1. Импорт оператора `gte` (greater than or equal) из Drizzle ORM:
```typescript
import { desc, sql, or, and, ilike, not, eq, gte } from 'drizzle-orm';
```

2. Добавлено условие фильтрации по дате:
```typescript
// Текущая дата (начало дня в UTC)
const today = new Date();
today.setHours(0, 0, 0, 0);

// Собираем все условия фильтрации
const whereConditions: any[] = [
  eq(cargo_messendger.irrelevant, 0),
  // Дата окончания груза должна быть не раньше сегодняшнего дня
  gte(cargo_messendger.date_end, today),
];
```

## Логика фильтрации

### Условие:
```sql
date_end >= CURRENT_DATE
```

Это означает:
- ✅ Показываются грузы, у которых дата окончания **сегодня** или **в будущем**
- ❌ Скрываются грузы, у которых дата окончания **вчера** и раньше

### Примеры:

| Дата окончания груза | Сегодня | Результат |
|---------------------|---------|-----------|
| 27.10.2025 | 28.10.2025 | ❌ Не показывается (просрочен) |
| 28.10.2025 | 28.10.2025 | ✅ Показывается (актуален сегодня) |
| 29.10.2025 | 28.10.2025 | ✅ Показывается (актуален завтра) |
| 30.10.2025 | 28.10.2025 | ✅ Показывается (актуален) |

## Существующие фильтры

Фильтр по дате работает **совместно** с другими фильтрами:

1. **irrelevant = 0** - не показываются грузы, помеченные как нерелевантные
2. **date_end >= today** - не показываются просроченные грузы
3. **contains** - текстовый поиск по ключевым словам (опционально)
4. **notContains** - исключение по ключевым словам (опционально)

Все условия объединяются через **AND**, то есть груз должен соответствовать всем условиям одновременно.

## Возможные проблемы

### Проблема 1: Грузы с датой "сегодня" не показываются

**Причина:** Возможно проблема с часовыми поясами.

**Решение:** 
- Проверить, что `today.setHours(0, 0, 0, 0)` устанавливает начало дня
- Убедиться, что в БД даты хранятся в UTC

### Проблема 2: Показываются просроченные грузы

**Причина:** Возможно кэширование на frontend или backend.

**Решение:**
- Очистить кэш браузера (Ctrl+Shift+R)
- Перезапустить backend
- Проверить, что фильтр применяется в SQL запросе

## SQL запрос после изменений

```sql
SELECT 
  cm.id_cargo,
  cm.departure_point,
  cm.arrival_point,
  cm.date_start,
  cm.date_end,
  tc.car_type as car_type_name,
  -- ... другие поля
FROM cargo_messendger cm
LEFT JOIN tip_car tc ON cm.id_car_type = tc.id_car_type
WHERE 
  cm.irrelevant = 0 
  AND cm.date_end >= CURRENT_DATE
  -- ... дополнительные фильтры (contains, notContains)
ORDER BY cm.id_cargo DESC
LIMIT 20
OFFSET 0;
```
