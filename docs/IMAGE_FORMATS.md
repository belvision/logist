# Форматы изображений для фоновых изображений

## ✅ Поддерживаемые форматы

### WebP (рекомендуется) ⭐

**Преимущества:**
- ✅ Меньший размер файла (на 25-35% меньше чем JPG)
- ✅ Лучшее качество при том же размере
- ✅ Поддержка прозрачности
- ✅ Поддержка всеми современными браузерами

**Рекомендации:**
- Размер: 1920x1080px или больше
- Размер файла: 100-300 KB (оптимально ~200 KB)
- Имя файла: `hero-bg.webp`

**Конвертация в WebP:**
- Онлайн: https://squoosh.app/ (Google)
- Программы: XnConvert, ImageMagick, Photoshop

### JPG (также поддерживается)

**Преимущества:**
- ✅ Универсальная поддержка
- ✅ Хорошее качество для фотографий

**Рекомендации:**
- Размер: 1920x1080px или больше
- Размер файла: 200-500 KB (оптимально ~300 KB)
- Имя файла: `hero-bg.jpg`

## 📋 Текущая конфигурация

В коде настроено использование **WebP** формата:

```typescript
// apps/frontend/src/lib/background-images.ts
home: {
  hero: getBackgroundImageUrl('home/hero-bg.webp'),
}
```

Если вы загрузите JPG, просто измените расширение в конфигурации или загрузите файл с именем `hero-bg.webp`.

## 🎯 Рекомендации

### Для лучшей производительности:

1. **Используйте WebP** - меньший размер = быстрая загрузка
2. **Оптимизируйте изображения** перед загрузкой:
   - WebP: качество 80-85%
   - JPG: качество 85-90%
3. **Проверьте размер файла** - должен быть < 500 KB

### Инструменты для оптимизации:

**Онлайн:**
- [Squoosh](https://squoosh.app/) - лучший инструмент от Google
- [TinyPNG](https://tinypng.com/) - сжатие JPG/PNG
- [ImageOptim](https://imageoptim.com/) - для Mac

**Программы:**
- **XnConvert** - бесплатная, поддерживает WebP
- **Photoshop** - File → Export → Save for Web (WebP)
- **GIMP** - с плагином WebP

## 📤 Загрузка изображений

### WebP формат:

```cmd
# Главная страница
C:\Users\23232323\Downloads\mc.exe cp hero-bg.webp myminio/logistic-pro/backgrounds/home/hero-bg.webp

# Перевозчики
C:\Users\23232323\Downloads\mc.exe cp carriers-bg.webp myminio/logistic-pro/backgrounds/carriers/hero-bg.webp
```

### JPG формат (если нужно):

Если используете JPG, измените конфигурацию в `apps/frontend/src/lib/background-images.ts`:

```typescript
home: {
  hero: getBackgroundImageUrl('home/hero-bg.jpg'), // измените .webp на .jpg
}
```

## 🔄 Автоматический fallback

Компонент `BackgroundImage` автоматически переключится на градиентный фон, если:
- Изображение не загрузилось
- Файл не найден
- Произошла ошибка загрузки

## ✅ Итог
