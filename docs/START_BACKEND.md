# Запуск Backend сервера

## Проблема

После очистки кэша появились ошибки:
- `ERR_CONNECTION_REFUSED` для `http://localhost:5555/api/...`
- WebSocket ошибки подключения

Это означает, что **backend сервер не запущен**.

## Решение

### Вариант 1: Запуск только Backend (в отдельном терминале)

```powershell
# Перейдите в папку backend
cd apps\backend

# Запустите dev сервер
npm run dev
```

Backend должен запуститься на порту **5555**.

### Вариант 2: Запуск Frontend и Backend вместе (из корня проекта)

```powershell
# Из корневой папки проекта
npm run dev
```

Это запустит оба сервера одновременно через Turbo.

## Проверка

После запуска backend вы должны увидеть в консоли:
```
Server running on http://0.0.0.0:5555
```

Или похожее сообщение о том, что сервер запущен.

## Важно

1. **Backend должен быть запущен** на порту 5555
2. **Frontend должен быть запущен** на порту 3000
3. Оба сервера должны работать **одновременно**

## Если backend не запускается

Проверьте:
1. Установлены ли зависимости: `cd apps/backend && npm install`
2. Настроен ли `.env` файл в `apps/backend/`
3. Запущена ли база данных PostgreSQL
4. Нет ли ошибок в консоли при запуске

---

**После запуска backend обновите страницу в браузере (F5).**
