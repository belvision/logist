# Проверка SEO после развертывания

## 🚀 Быстрая проверка (5 минут)

### 1. Проверьте исходный HTML страницы

Откройте сайт и посмотрите исходный код:

```bash
# В браузере: Правая кнопка мыши → "Просмотр кода страницы" (View Page Source)
# Или нажмите Ctrl+U / Cmd+U
```

**Что искать**:
```html
<title>Международная биржа грузоперевозок | Беларусь, Россия...</title>
<meta name="description" content="Международная биржа грузоперевозок LogistGo.pro...">
<meta property="og:title" content="LogistGo.pro - Международная биржа грузоперевозок">
```

✅ **Если мета-теги есть в исходном HTML** - всё работает правильно!  
❌ **Если мета-тегов нет** - проблема с рендерингом на сервере

### 2. Проверьте Open Graph теги

Используйте Facebook Debugger:

```
https://developers.facebook.com/tools/debug/
```

1. Вставьте URL: `https://logistgo.pro`
2. Нажмите "Debug"
3. Проверьте, что отображаются:
   - Заголовок (title)
   - Описание (description)
   - Изображение (если добавлено)

### 3. Проверьте структурированные данные

Используйте Google Rich Results Test:

```
https://search.google.com/test/rich-results
```

1. Вставьте URL: `https://logistgo.pro`
2. Нажмите "Test URL"
3. Проверьте, что Schema.org данные валидны

### 4. Проверьте sitemap.xml и robots.txt

```bash
# Откройте в браузере
https://logistgo.pro/sitemap.xml
https://logistgo.pro/robots.txt
```

✅ Оба файла должны быть доступны

## 📊 Подключение инструментов мониторинга

### Google Search Console

1. Перейдите: https://search.google.com/search-console
2. Добавьте сайт: `https://logistgo.pro`
3. Подтвердите владение через meta-тег (уже есть в layout.tsx):
   ```html
   <meta name="google-site-search-verify" content="your-code">
   ```
4. Отправьте sitemap.xml:
   - В меню: "Sitemaps"
   - Добавьте: `https://logistgo.pro/sitemap.xml`

### Yandex Webmaster

1. Перейдите: https://webmaster.yandex.ru
2. Добавьте сайт: `https://logistgo.pro`
3. Подтвердите владение через meta-тег (уже есть в layout.tsx):
   ```html
   <meta name="yandex-verification" content="your-code">
   ```
4. Отправьте sitemap.xml в настройках индексирования

1. Перейдите в "URL Inspection"
2. Введите URL страницы
3. Нажмите "Request Indexing"
4. Повторите для всех важных страниц:
   - https://logistgo.pro
   - https://logistgo.pro/cargo-owners
   - https://logistgo.pro/carriers

### В Yandex Webmaster

1. Перейдите в "Индексирование" → "Переобход страниц"
2. Добавьте URLs для переобхода
3. Нажмите "Добавить"

## ⚠️ Частые проблемы

### Проблема: Описание не отображается в Google

**Причина**: Google сам генерирует описание из контента страницы

**Решение**: 
- Подождать 2-4 недели
- Убедиться, что meta description уникален и информативен
- Проверить, что контент страницы релевантен запросу

### Проблема: Страницы не индексируются

**Причина**: robots.txt блокирует или нет sitemap.xml

**Решение**:
- Проверить robots.txt на наличие Disallow для публичных страниц
- Убедиться, что sitemap.xml указан в robots.txt
- Отправить sitemap.xml в Search Console

### Проблема: Дубли страниц

**Причина**: www и non-www версии, http и https

**Решение**:
- Настроить редиректы в nginx
- Указать canonical URLs
- Проверить настройки в Search Console
